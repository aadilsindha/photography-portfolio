# Photography Portfolio

Single-page photography portfolio built with plain HTML5 and CSS3 (no frameworks).
Group project, CTU Training Solutions.

## Features
- Responsive CSS Grid image gallery using `object-fit: cover`
- Flexbox header, services, about and footer
- Semantic landmarks, one `h1`, in-page navigation
- CSS custom properties for the colour palette

## Run it
Open `index.html` in a browser.
